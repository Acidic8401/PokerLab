# Playing card artwork

PokerLab uses the 52 PNG face assets from the free playing-card asset pack by Victor MEUNIER (MrEliptik). The pack is dedicated to the public domain under CC0; see [PLAYING-CARDS-LICENSE.txt](./PLAYING-CARDS-LICENSE.txt). The assets are bundled locally for offline use.

PokerLab uses the dark `black` variants for clubs and spades, and the light `white` variants for hearts and diamonds. Card indexes are part of the original artwork; no extra rank or suit overlay is added.
