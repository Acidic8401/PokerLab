# Playing card artwork

The SVG card faces and backs in `cards/` are from [letele/playing-cards](https://github.com/letele/playing-cards), converted from Adrian Kennard's SVG and print-ready playing card designs.

The repository distributes these assets under the [CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/). They are bundled locally so PokerLab card faces work offline in the browser and desktop app.
